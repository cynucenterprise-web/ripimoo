# Security

This repository is a front-end showcase only — the backend, auth, payment,
and AI pipeline code live in a private repository and aren't visible here.

## Reporting a vulnerability

If you believe you've found a security issue affecting [ripimoo.com](https://ripimoo.com)
or Ripimoo's systems, please report it by email to **support@ripimoo.com**
rather than opening a public issue.

Please include enough detail to reproduce the issue. We'll acknowledge your
report and follow up as soon as we can.
